# Getting Started & Practice Methodology

### Source: YouTube Video (FTFaQWZBqQ8)

### Concrete Rules
- **Zero-to-One Avoidance for Beginners:** Never start raw UI/UX design with a blank artboard if you lack foundational knowledge of design principles, spacing tokens, and grid alignment.
- **Reverse-Engineering via Template Cloning:** Accelerate mastery by duplicating existing production-grade UI kits (e.g., Figma Community templates like Food Delivery App UI) directly into personal drafts.
- **Progressive Fidelity Staircase:**
  1. *Phase 1 (Imitation):* Copy existing templates line-for-line to decode how master designers achieve specific visual hierarchies and interactions.
  2. *Phase 2 (Recreation):* Rebuild proprietary app interfaces (e.g., Instagram, TikTok) from scratch.
  3. *Phase 3 (Innovation/Improvement):* Redesign existing flawed enterprise/banking applications using established design systems.

- **Copy / Paste Style/Element:** `Cmd + C` / `Cmd + V` (Mac) or `Ctrl + C` / `Ctrl + V` (Windows)
- **Undo:** `Cmd + Z` / `Ctrl + Z`
- **Inspect Padding/Distance:** Hold `Option` (Mac) / `Alt` (Windows) while hovering over sibling elements.
- **Uniform Scale:** Hold `Shift` while dragging bounding boxes or resize handles.
- **Center-Out Scale:** Hold `Shift + Option` (Mac) / `Shift + Alt` (Windows).

### Anti-Patterns to Avoid
- Designing in a vacuum without dissecting existing structural hierarchies.
- Attempting to monetize or claim ownership of cloned training files.
- Staring at empty artboards waiting for inspiration instead of studying production file layer panels.
